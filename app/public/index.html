⚠️ Demo Tamper — Simulasi Serangan

Eksperimen untuk memahami konsep tamper evidence dalam blockchain

🎓

Fitur Pembelajaran

Fitur ini hanya untuk tujuan edukasi. Anda dapat memanipulasi data block untuk melihat bagaimana blockchain mendeteksi perubahan. Setelah selesai, klik Restore untuk mengembalikan data asli.

🔧 Manipulasi Data Block

Block 0 adalah genesis block, tidak dapat dimanipulasi. Mulai dari block 1.

📊 Hasil Eksperimen

🔬

Belum ada eksperimen

Lakukan manipulasi block, lalu klik Verifikasi untuk melihat hasilnya

📖 Panduan Skenario Eksperimen

Langkah 1

Buka halaman Verifikasi dan konfirmasi blockchain valid ✅

Langkah 2

Kembali ke halaman ini, pilih block dan manipulasi datanya 💥

Langkah 3

Kembali ke Verifikasi dan lihat hasilnya — blockchain menjadi invalid ✗

Langkah 4

Klik Restore untuk mengembalikan chain ke kondisi valid 🔄
